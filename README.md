# Student Record Manager

A simple **Python-based Student Record Management System** that allows users to add and view student records through a menu-driven console application.

## Features

* Add student details such as:

  * Student ID
  * Name
  * Email
  * Age
* Validate email addresses using **Regular Expressions (Regex)**.
* Validate student name and age.
* Store student records in a `students.txt` file.
* Read and display saved student records.
* Handle invalid input and file-related errors using exception handling.
* Simple menu-driven interface with Add, Read, and Exit options.

## Technologies Used

* Python
* Regular Expressions (`re`)
* File Handling
* Exception Handling

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the Python file:

```bash
python student-record-manager.py
```

4. Select an option from the menu and enter the required student details.

## Project Purpose

This project was created to practice **Python fundamentals**, including functions, conditional statements, loops, file handling, regular expressions, and exception handling.
